# 商超散称称差稽核数据与算法

导入自备批次或复核估计时阅读。先核对下面的字段和时间窗。查看隔离行原因，再核对估计和派发结果。

## 单据

| 字段 | 用途 | 单位 | 有效区间 |
|---|---|---|---|
| `ticket_g` | 标签重量 | g | 120–3300 |
| `actual_g` | 抽秤实际 | g | 90–3300 |
| `tare_g` | 扣皮重量 | g | 6–120 |
| `temp_c` | 秤台温度 | ℃ | 12–37 |
| `bins` | 称台分拣格 | 格 | 2–21 |
| `return_g` | 退秤扣减 | g | 0–155 |

`key` 是单号，`cohort` 是作业区，文本先做 NFKC 归一化。`day` 为测量工日，`received` 为到站工日，`revision` 为正整数版次。同版记录出现多个不同测量结果时隔离该单全部版次。缺测可空置，但每条单至少包含四项观测。

`outcome` 与 `result_day` 成对填写。标签 0 为已核实正常，1 为需要复核的实绩。 `observed` 省略时为 `true`，只在留架右截尾场景允许 `false`。

### 原始行业单据

允许使用 `form` 对象代替平铺量测。保留单号、版次、工日和标签等顶层字段。表中的换算为 `(单据值 − 原点偏移) / 倍率`。每行内部校验完成后，与平铺数据使用同一分窗、建模和派单过程。

| 单据组 | 原始字段 | 用途 | 倍率 | 原点偏移 |
|---|---|---|---:|---:|
| 散称签面 | `label_mg` | 签面净量毫克 | 1000 | 0 |
| 散称签面 | `scale_mg` | 实秤毛量毫克 | 1000 | 0 |
| 抽秤净毛 | `tare_mg` | 扣皮量毫克 | 1000 | 0 |
| 抽秤净毛 | `probe_deci_c` | 秤头读数十分度 | 10 | 0 |
| 退秤补签 | `scale_bins` | 混放格数 | 1 | 0 |
| 退秤补签 | `void_mg` | 退秤回冲毫克 | 1000 | 0 |

示例见 `sample_data/scale_slips_form.json`。混合使用两种量测表示，或单据内读数互相矛盾时，保留隔离原因。

## 时序与训练

拟合 `[1,40)`、校准 `[42,63)`、回放 `[65,84)`、当班从 `88` 日起。前三个窗口的入站和结果都须早于窗口终点。到站日晚于截止日的单据在入站隔离。拟合期冻结补值中位数、均值、尺度及训练包络。

| 特征 | 语义 | 公式 |
|---|---|---|
| `net_gap` | 相对实称差 | `(actual_g-tare_g-ticket_g+return_g)/max(100,ticket_g)` |
| `tare_ratio` | 扣皮比 | `tare_g/ticket_g` |
| `return_rate` | 退秤比 | `return_g/(actual_g+1)` |
| `thermal_offset` | 温漂因子 | `abs(temp_c-24)/12` |
| `bin_load` | 分拣格负荷 | `bins/(1+ticket_g/350)` |

### 分店 MAD 稳健标定

用已确认常态称签估计中心和 MAD，样本不足的门店回退至全链。实称差作为主要异常指标。

本工作台的独立样本校准方式为称差幂曲线复标。风险校准无法确认正负样本时转人工判读。连续估计使用独立校准残差计算双侧区间，误差尺度随作业条件变化。分布监测对训练和当班量测比较分位位移。未知作业区、两项缺测或两项明显超训练包络的单据需要人工判读。

### 各作业区当班校准选用

称差回放按 `cohort`（作业区）判定当班使用哪套校准。分区候选只能用**同区 + 校准窗 `[42,63)`** 的已确认实绩经 `prepare_verification` 拟合；回放窗 `[65,84)` 只用于判定，其标签不回灌拟合，避免标签泄漏抬高成绩。全场基线仍由全部作业区的校准窗实绩拟合。

某区启用分区校准必须同时满足，否则沿用全场校准：

1. 本区回放有已确认正常签（`outcome=0`）和异常签（`outcome=1`）；
2. 以 `0.6` 为命中线，旧版（全场校准）在本区抓住的异常单全部仍被分区校准抓住（`旧版命中 ⊆ 本区命中`，一张不丢）；
3. 分区校准对正常签的误报数严格少于旧版（确有正常签少报、腾出复秤位）。

校准结论与缘由写入第 5 环节“称差回放”的分区判定表（原因码：`COHORT_CALIBRATION_ADOPTED`、`REPLAY_MISSING_ABNORMAL`、`REPLAY_MISSING_NORMAL`、`RECALL_REGRESSION`、`FALSE_ALARM_NOT_REDUCED`、`COHORT_CALIBRATION_INSUFFICIENT`），并在报告顶层 `calibration_choices` / `cohort_calibration` 给出结构化结果。当班出分、干预推演与复秤派发都按各作业区选定的校准计算；未知作业区回退全场校准。分区结论只依赖单据内容并按键排序规范化，输入换序重算结论一致，且不随 `capacity`/`strategy` 改变。

## 安排称差复秤

| 优先级 | 原因码 | 条件 | 处置依据 |
|---:|---|---|---|
| 1 | `UNDERRECORDED_TARE` | `tare_g >= 99 and ticket_g <= 350` | 先隔离扣皮码 |
| 2 | `RETURN_DISPUTE` | `return_g >= 95 and actual_g < ticket_g` | 退秤读数和标签不符 |
| 3 | `BIN_MIX` | `bins >= 16 and abs(actual_g-ticket_g) > 165` | 复查混放格 |

第一条为暂停规则。其余命中与模型阈值 `0.6` 共同决定是否列入候选。单据所需工位数按 `1 + int(ticket_g >= 1500)` 计算。均衡策略对分区限额，集中复核策略允许把额度集中投入高风险区。未分派原因在导出的处置记录中保留。签发前核对每张当班单和工位余额。

### 逐票复秤凭证

样例的抽秤读数为毛重。逐票按克四舍五入，再扣皮重和已退秤量。短量和多量分别累加，扣减超过净量的标签单列复核。 在派发环节展开现场安排，或从关联单据回查实际读数。
